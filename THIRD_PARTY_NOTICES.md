# File catalog data sources

The built-in catalog contains extension and format-name facts curated from macOS CoreTypes declarations, GitHub Linguist and mime-db. Raw upstream databases are not bundled. Compound suffixes and directory bundles are excluded; extensions are normalized and deduplicated for the UI.
